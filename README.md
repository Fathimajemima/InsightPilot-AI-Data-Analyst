# InsightPilot AI — Your AI Data Analyst

An AI-powered data analytics web application that helps users explore datasets, generate visualizations, identify business insights, and ask data-related questions using natural language.

## Live Demo

[Launch InsightPilot AI](https://insightpilot-ai-your-ai-data-analyst-345509340269.asia-south1.run.app)

## Project Overview

Analyzing business data manually can be time-consuming. InsightPilot AI aims to simplify data analysis by combining interactive data exploration with AI-assisted insights and reporting.

## Key Features

- **Data Upload:** Import supported datasets for analysis.
- **Data Visualization:** Explore data using different chart types.
- **KPI Analysis:** Calculate relevant business performance metrics.
- **AI Data Analysis:** Ask questions about uploaded data in natural language.
- **Data Cleaning:** Identify missing values, duplicates, and potential data-quality issues.
- **AI SQL Assistant:** Generate SQL queries for analytical questions.
- **Business Reports:** Summarize findings and recommendations.

*Features depend on the implemented functionality and supported file formats.*

## Technology Stack

- **AI Development:** Google AI Studio
- **Frontend Build Tool:** Vite
- **Programming Languages:** TypeScript, JavaScript, HTML, CSS
- **Backend Runtime:** Node.js with TypeScript
- **Package Management:** Bun
- **Cloud Deployment:** Google Cloud Run
- **Version Control:** Git and GitHub

## How to Use

1. Open the [live application](https://insightpilot-ai-your-ai-data-analyst-345509340269.asia-south1.run.app).
2. Upload a supported dataset.
3. Explore the data and available visualizations.
4. Ask analytical questions about the dataset.
5. Review the generated insights and reports.

## Project Objective

The goal of InsightPilot AI is to make data exploration more accessible and help users turn raw data into understandable, evidence-based business insights.
